HelloIAM Studio

Импортируйте CSS, правьте props в галерее (кнопка «Редактировать») или откройте шаблон в Remotion Studio — оба пути валидны.

Импорт из Figma CSS

Загрузите .css или вставьте экспорт из Figma — шаблон создастся без нейросети.

Изображения

Загрузите PNG/JPG/WEBP — путь появится в props image в Remotion Studio.

Запускаем Remotion Studio…

Галерея: «Редактировать» → сохранение пишет meta.json (используется при рендере). Studio: http://localhost:3000 — кнопка «Открыть» или npm run studio; правки в панели props сессионные, пока не сохраните через галерею.

## Другое (hello i am)

Палитра фоновых цветов для постов — выбирается на шаге «Настройка» в студии (предустановленные swatch'и).

| Токен Figma | HEX | Название |
|-------------|-----|----------|
| 34 | `#FFFFFF` | Белый |
| 39 | `#D9DDE0` | Серый |
| 40 | `#FFC53A` | Жёлтый |
| 41 | `#D61E23` | Красный |
| 44 | `#4A7BFF` | Синий |
| 45 | `#1E1E1E` | Чёрный |

Источник в коде: `tools/posts/post-settings.mjs` → `BRAND_COLORS`.

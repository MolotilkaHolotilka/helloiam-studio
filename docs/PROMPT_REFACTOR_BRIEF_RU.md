# Рефакторинг промптов HelloIAM

Документ для передачи разработчику. Цель — описать новую структуру промптов для генерации контента HelloIAM под направление: туры из Англии в Армению.

## 1. Главная задача промптов

Мы больше не генерируем просто “контент про Армению”.

Новая задача:

> Создавать Instagram-контент, который показывает Армению как яркое, теплое, культурное и неожиданное направление для туров из Англии.

Контент должен цеплять англичан 20–50 лет и вызывать желание поехать в Армению.

## 2. Общий слой: направление бренда

Этот слой применяется к рубрикам:

- Promo 01
- Promo 02
- Item 01
- Item 02

```text
Ты создаешь Instagram-контент для HelloIAM, продвигающий туры из Англии в Армению.

Аудитория:
Англоязычные жители Великобритании 20–50 лет, которым интересны культура, еда, места, дизайн, история и необычный travel experience.

Креативное направление:
Показывай Армению живой, теплой, неожиданной, древней и современной одновременно, культурно насыщенной и достойной поездки. Каждый предмет, место или культурный объект должен ощущаться как маленькая причина приехать в Армению.

Тон:
Теплый, умный, немного ироничный, editorial, цепляющий, с вайбом армянской культуры. Не формальный. Не туристическая брошюра.

Правила достоверности:
Не выдумывай исторические факты, цифры, даты, происхождение, события или claims.
Если факт не дан пользователем и ты не уверен, описывай атмосферу, визуальную деталь, культурное ощущение или travel appeal вместо фактологического утверждения.

Правила предмета:
Понимай предмет буквально.
Если предмет — место, объект, достопримечательность, игра, документ, ритуал, звук или культурный символ, сохраняй его категорию и узнаваемые признаки.
Не давай общей стилистике или category переопределять сам subject.

Визуальные правила:
Контекст должен быть реалистичным и каноничным для Армении.
Все кадры должны быть разными.
Используй разные композиции, ракурсы, места, освещение и визуальные исполнения.
Предмет должен оставаться узнаваемым и реалистичным.
Без текста на изображениях и видео.
Без логотипов, интерфейса и водяных знаков.
```

## 3. Общий слой: точность subject

Этот слой нужен, чтобы генерация держалась за фактический предмет пользователя и не уходила в произвольную красивую сцену.

```text
Всегда трактуй subject буквально.

Subject важнее общей темы, category и визуального стиля.

Если пользователь дал конкретный предмет, место или культурный объект:
- сохрани его категорию;
- сохрани его узнаваемые признаки;
- показывай его реалистично для армянского контекста;
- не заменяй его похожим, более “красивым” или более удобным объектом.

Если факта о subject нет:
- не придумывай факт;
- пиши или визуализируй атмосферу, travel appeal, материал, форму, место, жест, настроение.

Примеры точности:
- BACKGAMMON — игра и социальный ритуал.
- ARMENIAN PASSPORT — документ и символ идентичности.
- ARARAT — гора, ландшафт и культурный символ.
- JUG — предмет/сосуд с формой, материалом и бытовым контекстом.
```

## 4. Promo 01: video prompt

Используется для рубрики `Promo 01`.

Вход:

- выбранный emoji/object;
- пользовательское описание сцены.

Выход:

- video prompt для генерации видео.

```text
Сгенерируй video prompt для одного слайда HelloIAM Promo 01.

Subject: {subject}
Пользовательское описание сцены: {userScene}

Цель:
Сделать subject маленькой, запоминающейся причиной поехать из Англии в Армению.

Правила:
- Понимай subject буквально.
- Сцена должна визуально отличаться от других слайдов.
- Используй реалистичные армянские места, материалы, свет, жесты или атмосферу.
- Легкое преувеличение разрешено ради эмоционального эффекта, но нельзя выдумывать факты.
- Опиши одно понятное движение камеры или одно простое движение объекта.
- Держи главный объект ближе к центру, с safe margins для итогового crop 1080x1350.
- Без текста, субтитров, интерфейса и логотипов.

Верни JSON:
{"cardIndex":{cardIndex},"videoPrompt":"one line prompt"}
```

## 5. Promo 02: video prompt

Используется для рубрики `Promo 02`.

Вход:

- 5 выбранных карточек;
- название каждой карточки становится subject для своего видео.

Выход:

- video prompt для каждого video-слайда.

```text
Сгенерируй video prompt для одного video-слайда Promo 02.

Точный subject карточки: {subject}

Цель:
Превратить этот точный армянский subject в travel hook для аудитории из Великобритании.

Правила:
- Покажи точный subject напрямую.
- Если это игра, объект, достопримечательность, документ, место, звук или культурный символ — оставь его в этой категории.
- Сцена должна показывать Армению живой, теплой, тактильной и достойной поездки.
- Используй разные визуальные исполнения: другой ракурс, место, движение, свет или атмосферу.
- Не выдумывай факты и исторические claims.
- Без текста, субтитров, интерфейса и логотипов.
- Держи subject по центру для итогового формата 1080x1350.

Верни JSON:
{"cardIndex":{cardIndex},"videoPrompt":"one line prompt"}
```

## 6. Item 01 / Item 02: генерация текстов

Используется для рубрик:

- `Item 01`
- `Item 02`

Вход:

- selected item / emoji;
- category / topic;
- card fields.

Выход:

- текст для слайдов.

```text
Сгенерируй текст для одного слайда HelloIAM item carousel.

Subject: {subject}
Category: {categoryLabel}
Card: {cardIndex} ({cardLabel})
Поля для заполнения: {textFields}

Креативное направление:
Сделай subject частью причины поехать в Армению из Англии.

Правила:
- Тон теплый, умный, немного ироничный, editorial.
- Текст должен цеплять, но не быть формальным.
- Не выдумывай факты.
- Если проверенный факт не дан, пиши про сенсорную деталь, культурное ощущение, travel appeal или то, как предмет/место ощущается в армянской жизни.
- Понимай subject буквально.
- Избегай туристических клише вроде “hidden gem”, “rich history”, “must-see destination”, если они не переосмыслены свежо.
- 1–2 компактных предложения.

Верни JSON:
{"cardIndex":{cardIndex},"props":{...}}
```

Цель:

Правила:
- Контекст должен быть каноничным и реалистичным для Армении.
- Subject должен быть точным и узнаваемым.
- Не выдумывай невозможные или исторически ложные детали.
- Изображение должно визуально отличаться от других слайдов.
- Используй конкретную композицию, место, освещение и ракурс.
- Без текста на изображении.
- Без логотипов и водяных знаков.

Верни JSON:

## 8. News: разбиение инфоповода

Для новостей логика проще: пользователь вводит инфоповод, а система делит его на 3 логические части.

Цель:

- не придумывать новых фактов;
- выделить главные сущности;
- сделать каждую часть визуализируемой;
- затем по каждой части создать image prompt.

```text
Раздели новостной инфоповод на 3 логические части для Instagram carousel.

Инфоповод: {subject}

Правила:
- Используй только информацию из пользовательского ввода.
- Не выдумывай факты, имена, цифры, обвинения, причины или последствия.
- Выдели главные сущности.
- Каждая часть должна быть визуализируемой как изображение.
- Язык: английский.
- Стиль: понятный, editorial, не формальный.
- Без политического преувеличения.
- Без инструкций сделать карикатуру на реального человека.

Верни JSON:
{
  "parts": [
    {
      "cardIndex":0,
      "text":"...",
      "mainEntities":["..."],
      "imageLogic":"..."
    },
    {
      "cardIndex":1,
      "text":"...",
      "mainEntities":["..."],
      "imageLogic":"..."
    },
    {
      "cardIndex":2,
      "text":"...",
      "mainEntities":["..."],
      "imageLogic":"..."
    }
  ]
}
```

## 9. News: image prompt

Используется после разбиения инфоповода на 3 части.

```text
Сгенерируй безопасный editorial illustration prompt для одной части news carousel.

Текст новости: {text}
Главные сущности: {mainEntities}
Логика изображения: {imageLogic}

Правила:
- Покажи ситуацию символически.
- Не изображай узнаваемого реального человека.
- Если нужны люди, используй unnamed figures или silhouettes.
- Не используй стили конкретных защищенных мультсериалов или франшиз.
- Без текста на изображении.
- Армянский контекст можно показывать через архитектуру, цвета, ландшафт, документы, публичные пространства или символические объекты.
- Изображение должно быть достаточно реалистичным, чтобы соответствовать логике новости, но визуально понятным для Instagram.

Верни JSON:
{"cardIndex":{cardIndex},"imagePrompt":"one line prompt"}
```

## 10. Emoji: генерация стикера

Используется для рубрики `Emoji`.

Вход:

- название предмета.

Выход:

- prompt для генерации isolated emoji/sticker.

```text
Сгенерируй один flat cartoon emoji sticker.

Subject: {name}

Правила:
- Покажи только один предмет.
- Предмет должен быть точным и узнаваемым.
- Белый или прозрачный фон.
- Центрированная композиция.
- Чистые простые линии.
- Мягкие натуральные цвета.
- Легкая тень допустима.
- Без текста.
- Без дополнительных объектов.
- Если subject является армянским культурным объектом, сохрани реалистичные узнаваемые признаки.

Верни prompt одной строкой.
```

## 12. Важные правила внедрения

1. Не смешивать весь prompt в один огромный текст.
2. Держать отдельно:
   - общий brand/direction слой;
   - правила буквального subject;
   - rubric-specific prompt;
   - step-specific prompt;
   - safety/provider constraints.
3. Для Promo 01 и Promo 02 не передавать category как смысловой источник.
4. Для Item 01 / Item 02 category можно использовать, но нельзя давать ей переопределять subject.
5. Для News сначала делать логическое разбиение инфоповода, потом image prompts.
6. Для изображений и видео всегда запрещать текст, логотипы, watermark и UI.

## 13. Хороший и плохой результат

Хорошо:

```text
A backgammon board as a quiet social ritual, not just a game.
```

Почему хорошо:

- subject понят буквально;
- есть культурный смысл;
- нет выдуманных фактов;
- звучит как цепляющий travel/editorial инсайт.

Плохо:

```text
Discover Armenia’s rich history and breathtaking hidden gems in an unforgettable journey.
```

Почему плохо:

- звучит как формальная туристическая брошюра;
- нет конкретного subject;
- нет живой детали;
- нет армянского культурного вайба;
- слишком общее и нецепляющее.

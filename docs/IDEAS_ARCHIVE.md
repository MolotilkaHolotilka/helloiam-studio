## Генерилка: BnB-плотность вкладок

**Статус:** зафиксировано как UI-референс (2026-06-19)

**Идея:** для редизайна генерилки использовать не pixel-perfect копирование, а паттерн плотности: верхний раздел `Контент`, внутри него компактные вкладки `Посты` / `Создать`, таблица вместо вертикальных карточек и рабочий экран с левой навигацией шагов.

**Что берём:** табличное сканирование списка, underline-active вкладки как views, sticky-превью справа, плотные контролы без больших маркетинговых блоков.

**Что не берём сейчас:** аналитику внутри поста, полный visual match, рефакторинг `picker.html` на модули.

## Settings: выбор пресета анимации

**Статус:** убрано из UI (2026-06-12)

**Что было:** блок на вкладке Settings поста — заголовок «Анимация слайдов» / «Пресет анимации», readonly-значение `presetId` (по умолчанию `soft-float`).

**Когда вернуть:** когда у шаблонов появится несколько `animations[]` / пресетов и пользователь должен выбирать анимацию в Settings (см. `PRODUCT_TZ.md` §3, §16).

**Технически:** поле `post.presetId` и бэкенд (`post-settings.mjs`, `posts-service.mjs`) остаются — менялся только UI в `picker.html` → `renderSettingsForm()`.

## PNG-рендер: генерировать отдельно, а не вырезать из видео

**Статус:** реализовано глобально для всех рубрик (2026-06-23)

**Идея:** PNG-кадры для каждого слайда генерируются отдельно через Remotion still-render, без создания видео и без вырезания кадра из MP4.

**Зачем:** чище, быстрее (не нужно кодировать весь видеоряд ради одного кадра), качество выше (нет артефактов видеосжатия), можно рендерить PNG и MP4 независимо.

**Технически:** `tools/render/render-composition.mjs` сначала запускает `npx remotion still ... --frame=... --props=...` для `still.png`. MP4 запускается отдельно через `npx remotion render ...` только если `options.video !== false`.

**Правило:** действует для всех текущих и будущих рубрик, потому что находится в общем render-layer, а не в логике конкретной RubricXX.

## Git hygiene: разбор рабочего дерева

**Статус:** отложено (2026-06-15)

**Что видно сейчас:** в git много незакоммиченных изменений: переименованные/удалённые emoji-assets, новые карточки и rubric-файлы, правки генерации, рендера, gallery UI, docker/config/docs.

**Почему отложили:** сейчас важнее разбирать продуктовый pipeline и текущую логику; чистка git может смешать продуктовые решения, assets и технические фиксы.

**Когда вернуть:** перед деплоем, PR или большой следующей итерацией, чтобы отделить рабочие изменения от мусора и случайных артефактов.

**Технически:** пройти `git status --short`, сгруппировать изменения по темам (assets, templates, generation, render, UI, docs/config), отдельно проверить `npm run lint`, затем решить что коммитить, что архивировать, а что удалить.

## Live card preview (Create + Pictures)

**Статус:** частично возвращено (2026-06-20)

**Create** (`#/content/create`): снова включено — обложки рубрик через `templateCoverHtml()` (`CARD_PREVIEW_IN_CREATE = true`).

**Технически:** флаги `CARD_PREVIEW_IN_CREATE` и `CARD_PREVIEW_IN_PICTURES` в `picker.html`. Превью на шагах Texts и Export остаётся. Вернуть Pictures — `CARD_PREVIEW_IN_PICTURES = true` или вынести в `app-config`.

## Promo 02: видео вместо изображений для 2n-слайдов

**Статус:** идея в архиве (2026-06-23)

**Идея:** для рубрики Promo 02 не генерировать статичные изображения на каждом `2n`-слайде, а генерировать отдельное видео для каждого такого слайда.

**Когда вернуть:** когда дойдём до отдельного video-generation workflow и решим, какой провайдер/модель будет отвечать за генерацию видео.

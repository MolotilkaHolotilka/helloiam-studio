# Rubric Pipeline Structure

Дата фиксации: 2026-06-24

Этот файл фиксирует текущую договоренность по структуре пайплайна для рубрик. Цель: видеть, какие шаги общие, какие скрываются, и откуда на каждом шаге берутся данные для текстов, промптов, изображений, видео и экспорта.

## Общие правила

1. Неиспользуемые шаги скрываются для конкретной рубрики.
2. Если в рубрике нет редактируемого текста слайда, шаг `Slide Text` не показывается.
3. `Media Prompt` означает подготовку описания для генерации картинки или видео.
4. `Media Prompt` может строиться из разных источников:
   - выбранный emoji/object;
   - выбранные карточки;
   - текст слайдов;
   - введенный пользователем предмет;
   - инфоповод новости.
5. `Media Generation` не является отдельной вкладкой. Это действие внутри media-шагов: по готовому промпту генерируется картинка или видео.
6. Для video-рубрик не используем category как смысловой источник промпта, чтобы объект не превращался в еду или другую неверную категорию.

## Promo 01

Текущий путь:

`Emoji -> Slide Videos -> MP4 Export`

### 1. Emoji

Пользователь выбирает emoji/object в настройках.

Используется:

- выбранный emoji/object;
- название выбранного объекта;
- без category в video prompt.

Не используется:

- ручной slide text;
- генерация текстов слайдов;
- topic/category как источник смысла.

### 2. Slide Videos

Пользователь пишет обстановку/сцену: что должно происходить в видео.

Дальше пользователь нажимает кнопку генерации video prompts.

Промпты берутся из:

- выбранного emoji/object;
- пользовательского описания сцены;
- rubric-specific video prompt template.

Медиа-генерация:

- генерируются video prompts;
- по video prompts генерируются видео;
- модель видео: `fal-ai/kling-video/v3/pro/text-to-video`;
- модель генерирует вертикальное видео, затем файл приводится к `1080x1350` (`4:5`) для Instagram feed;
- длительность: обычная генерация 5 секунд, короткая кнопка 3 секунды.

### 3. MP4 Export

Экспортируется только MP4.

Не используется:

- PNG preview как обязательный шаг;
- сборка финального видео из вырезанных кадров PNG.

## Promo 02

Текущий путь:

`Cards -> Slide Videos -> MP4 Export`

### 1. Cards

Пользователь выбирает 5 карточек.

Используется:

- 5 выбранных карточек из `ALL CARDS`;
- название каждой выбранной карточки;
- каждая карточка становится объектом для своего video prompt.

Не используется:

- category;
- topic;
- ручной slide text.

### 2. Slide Videos

Пользователь ничего не пишет.

Пользователь нажимает генерацию video prompts по выбранным карточкам.

Промпты берутся из:

- названий выбранных карточек;
- rubric-specific video prompt template;
- без category и без food context.

Медиа-генерация:

- генерируются video prompts;
- по video prompts генерируются видео;
- видео генерируются параллельно;
- модель видео: `fal-ai/kling-video/v3/pro/text-to-video`;
- модель генерирует вертикальное видео, затем файл приводится к `1080x1350` (`4:5`) для Instagram feed;
- длительность: обычная генерация 5 секунд, короткая кнопка 3 секунды.

### 3. MP4 Export

Экспорт идет как сейчас:

- статичные PNG-карточки HELLO I AM;
- raw MP4-видео, сгенерированные по video prompts;
- Remotion не трогает готовые MP4-видео;
- результат чередуется как sequence: PNG card + generated MP4 video.

## Item 01

Текущий путь:

`Post Settings -> Slide Text -> Slide Pictures -> Export`

### 1. Post Settings

Пользователь выбирает предмет/emoji/item для рубрики.

Используется:

- выбранный предмет;
- category/topic;
- color scheme;
- базовая структура слайдов рубрики.

### 2. Slide Text

Генерируются тексты слайдов.

Промпты берутся из:

- выбранного предмета;
- category/categoryLabel;
- text prompt template для item-рубрик;
- few-shot/стилевых инструкций, если они включены для этой рубрики.

Пользователь может редактировать тексты, если на слайде есть редактируемый текст.

### 3. Slide Pictures

Генерируются picture prompts.

На этом шаге не показываются:

- слайд 1;
- слайд 3.

Промпты для картинок берутся из:

- текстов слайдов;
- выбранного предмета;
- image prompt template для item-рубрик;
- общего image-style.

Медиа-генерация:

- по picture prompts генерируются картинки;
- модель изображений: `fal-ai/nano-banana-2`.
- aspect ratio для генерации: `3:2` (ближайший поддерживаемый banana-формат к placeholder `1024x645`).

### 4. Export

Экспорт:

- PNG через Remotion как статичные кадры без анимации;
- опционально MP4 через Remotion, если нужен видеоэкспорт;
- архив с результатами.

## News 01

Текущий путь:

`Post Settings -> Slide Text -> Slide Pictures -> Export`

### 1. Post Settings

Пользователь вводит инфоповод/news hook.

Используется:

- инфоповод;
- news-specific поля;
- news-specific структура слайдов.

Не используется:

- emoji как обязательный источник;
- category-driven item subject.

### 2. Slide Text

Генерируются news-тексты.

Промпты берутся из:

- инфоповода;
- news text prompt template;
- правил тона и структуры News 01.

### 3. Slide Pictures

Генерируются picture prompts.

Промпты для картинок берутся из:

- текстов news-слайдов;
- инфоповода;
- news image prompt template;
- news-specific визуального стиля.

Медиа-генерация:

- по picture prompts генерируются картинки;
- модель изображений: `fal-ai/nano-banana-2`, если используется общий image pipeline.
- aspect ratio для генерации:
  - слайд 1: `5:4` (ближайший поддерживаемый banana-формат к placeholder `1024x829`);
  - остальные generated image slides: `16:9` (ближайший поддерживаемый banana-формат к placeholder `1000x556` / `1000x543`).

### 4. Export

Экспорт:

- PNG через Remotion как статичные кадры без анимации;
- опционально MP4 через Remotion;
- проверка брендового NEWS-слайда.

## Emoji 01

Текущий путь:

`Subject -> Image Prompt -> Review -> PNG Export`

### 1. Subject

Пользователь вводит предмет.

Используется:

- введенный предмет;
- без category;
- без carousel cards.

### 2. Image Prompt

Генерируется промпт/результат для emoji-style изображения на основании предмета.

Промпты берутся из:

- введенного предмета;
- emoji-specific prompt templates:
  - `emoji-openai-edits`;
  - `emoji-openai-generations`;
  - `emoji-recraft`.

Медиа-генерация:

- генерируется изолированное emoji-style PNG;
- результат должен быть пригоден для библиотеки `ALL EMOJIS`.

### 3. Review

Пользователь проверяет сгенерированное изображение.

Можно:

- принять результат;
- вернуться и перегенерировать.

### 4. PNG Export

Экспорт:

- PNG сохраняется в библиотеку `ALL EMOJIS`;
- результат может использоваться в других рубриках.

Не используется:

- Remotion carousel export;
- slide text;
- video generation.

## Что можно сделать общим

Кандидаты на общие механики:

1. Пошаговая навигация с проверкой готовности шага.
2. Скрытие неиспользуемых шагов по рубрике.
3. Генерация prompts из источника рубрики.
4. Отдельная проверка: есть ли editable text / prompt / generated media.
5. Параллельная генерация media по списку prompts.
6. Static PNG export без анимации через Remotion.
7. Общая библиотека prompts, сгруппированная по рубрике и шагу.

## Что остается уникальным по рубрикам

1. Источник смысла:
   - Promo 01: выбранный emoji/object + сцена пользователя.
   - Promo 02: названия выбранных карточек.
   - Items: выбранный предмет + category + slide texts.
   - News: инфоповод + news slide texts.
   - Emoji: введенный предмет.
2. Наличие или отсутствие `Slide Text`.
3. Тип media:
   - images;
   - videos;
   - mixed PNG + MP4 sequence;
   - single emoji PNG.
4. Правила экспорта.
5. Использование category.
6. Prompt templates.
